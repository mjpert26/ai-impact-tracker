📐 Methodology & definitions
What "commission influenced" means. The sum of csbs__Commission_Amount__c on Salesforce opportunities that (a) reached StageName = Funded and (b) carry an in-house AI bot value in the multi-select Assisted_by__c field. It is influence, not sole credit — a bot touched the deal; humans closed it.

Scope — in-house AI bots only. This dashboard counts only BTC's in-house bots (Emma, Megan, Olivia, Faith, Anne, Jasmine, Gianna, Lauren, Inbox Manager). It deliberately excludes vendor/tool assists (Apten, Instantly, TextUs), the generic "Marketing" tag, call-center and human rep assists — so an "all Assisted-by values" Salesforce report will show a larger total. That's a scope difference, not a data discrepancy: for the shared bot values the two match within filter semantics (this dashboard uses INCLUDES, which correctly counts deals carrying multiple tags; "equals" filters drop them).

Attribution = last milestone-writer. Bots overwrite Assisted_by__c with a single value, so a deal is credited to the last bot that worked it. Per-bot figures sum exactly to the headline (verified — no double-counting).

Known caveat (resolved). A misconfigured bot briefly wrote Marketing - EW (Emma's tag) on its own leads; fixed at source 2026-06-29. Sizing the residual: that bot's sub-account shows ~41 total conversations with zero funded matches, so the impact on Emma's figure is immaterial. Every active bot now writes its own tag (verified in a full live-path audit of the production instance).

Refresh. Salesforce commission + GoHighLevel replies are pulled nightly into the Supabase ai_impact mart; this dashboard reads it live with a baked snapshot as fallback.
